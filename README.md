# RusTale

**RusTale** is a custom launcher for Hytale designed to be fast, lightweight, and easy to use. Forget complex configurations; just open, customize, and play.

![RusTale Banner](assets/banner.png)

## ✨ Main Features

### 🎮 Game Experience
*   Create and switch between multiple user profiles easily. Ideal for sharing the PC or managing multiple accounts.
*   Need to get in fast? Enter the game instantly with your last used profile with a single click using QuickPlay.
*   Play on any unofficial server, compatible with community private servers.

### 🛠️ Personalization 
*   Install and organize your mods easily by versions
*   Apply zip mods to the game automatically
*   Local server development.

### ⚡ Convenience
*   Designed to consume minimal resources while playing.
*   Automatically detects and installs updates to keep you on the latest version.
*   Minimizes the launcher to the system tray to keep your desktop clean while playing.
